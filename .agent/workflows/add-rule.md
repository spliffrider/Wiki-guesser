# Add/Modify Global Rule

Use this workflow to propose changes to the global rules in RULES.md.

## Process

1. **Describe the rule** you want to add or modify
2. **Explain why** - What problem does it solve?
3. **Give an example** of when this rule would apply

## Paul's Review

Paul will:
1. Check if a similar rule already exists
2. Evaluate if the rule is necessary
3. Ensure it doesn't conflict with existing rules
4. Propose the XML-formatted rule
5. Add it to RULES.md

## Reminder

After adding to RULES.md, you'll need to update your Gemini global settings with the new rule content for it to actually apply.
